title: "小团队默认技术选型"
---

| 层 | 建议 | 暂缓 |
| --- | --- | --- |
| 应用 | 团队会的单体（Java / .NET / Django 等） | 一上来拆十几微服务 |
| 数据 | PostgreSQL 或单位已有的 MySQL | 多种数据库混用 |
| 入口 | Nginx + HTTPS（内网也要） | 把应用端口直接暴露 |
| 运行 | Docker Compose 或 systemd | 无专职人员就上 K8s |
| 协作 | Git + 代码评审 + 自动构建 | 生产服务器上直接改文件 |

原则：五年后还能招到人维护，就算选对了。
